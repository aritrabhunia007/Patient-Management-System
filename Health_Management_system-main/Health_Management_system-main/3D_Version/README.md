# CareSync - 3D Version Frontend

This folder contains the visually updated 3D Neumorphic version of the CareSync Patient Management System frontend.

## Features

- **Dashboard**: Overview of total patients, active treatments, and upcoming follow-ups with interactive charts.
- **Patients Directory**: List of active and discharged patients with the ability to add, edit, or remove entries.
- **Treatments & Medications**: Dedicated tracker for ongoing patient care.
- **History (New)**: View a comprehensive history of all patients including past and present.
- **Notifications & Profile**: Interactive modals displaying new events and user profile details.

## Running Locally

To view the frontend:
1. Simply open `index.html` in any modern web browser.
2. Toggle the dark/light theme to see the 3D aesthetic shifts.

## Data

Currently, the application relies on mock data provided in `js/app.js`. Future iterations can connect to the Flask/SQL backend.
